# Superstore Sales Analysis Dashboard

## Project Overview
This project presents an interactive Superstore Sales Analysis Dashboard developed using Microsoft Power BI. It provides insights into sales, profit, product performance, regional performance, and business trends.

## Dashboard Features
- Total Sales, Total Profit, Total Orders, Total Quantity and Average Discount.
- Monthly Sales Trend.
- Sales by Category.
- Sales by Region.
- Profit by Category.
- Monthly Profit Trend.
- Top 10 Products by Profit.
- Sales Distribution by State.
- Sales by Segment.

## Tools & Technologies
- Microsoft Power BI
- Data Analysis
- Data Visualization
- Business Intelligence

## Key Insights
The dashboard helps analyze sales and profitability across different categories, regions, products, and customer segments.
